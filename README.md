# My Seat

서울 대표 간선버스와 KTX에서 **탑승 날짜·시각·이동방향**을 바탕으로 차량 진행방향 기준 왼쪽/오른쪽 중 직사광을 덜 받는 쪽을 추천하는 정적 웹앱입니다.

## 특징
- 날짜 자체가 계절을 반영하므로 별도 계절 선택 불필요
- 이동 중 경로 방위와 태양 방위각·고도를 구간별 계산
- 버스는 평일 출퇴근/일반 시간대의 정적 평균속도 차이를 반영
- KTX는 노선별 대표 평균속도를 사용해 이동 중 태양 위치를 갱신
- PWA 설치 가능, 오프라인 캐시 지원

## 지원 데이터
### 서울 간선버스
미아사거리역 중앙차로를 지나는 간선버스 15개 노선과 121, 152, 273의 주요 정류장을 포함합니다. 지원 번호는 101, 102, 107, 120, 121, 130, 140, 141, 142, 144, 148, 150, 151, 152, 160, 163, 273, 710입니다.

### KTX
경부선, 호남선, 전라선, 경전선, 강릉선 KTX-이음, 중앙선 KTX-이음의 주요 역.

## 계산 모델
1. 정류장/역 좌표 사이를 segment로 나눕니다.
2. segment의 진행 방위각을 구합니다.
3. 해당 segment 중간 시각과 위치에서 NOAA 근사식으로 태양 방위각/고도를 구합니다.
4. 차량 진행방향 기준 좌창 법선 = `bearing - 90°`, 우창 법선 = `bearing + 90°`로 둡니다.
5. 태양 방향과 창 법선의 수평 투영 내적, 태양고도 기반 대기/입사 가중치, 구간 시간을 곱해 누적합니다.
6. 누적 직사광 지표가 낮은 쪽을 추천합니다.

> 결과는 맑은 날의 **직달일사 방향성**을 비교하는 지표입니다. 건물, 터널, 방음벽, 교량 구조물, 차광필름, 커튼, 좌석 자체의 그늘, 구름은 반영하지 않습니다.

## 출처 및 검증 기준
- 서울 열린데이터광장: 버스노선경로 목록정보, 버스노선별 경유정류소 목록정보 (서울특별시, 공공누리 1유형)
- 서울시/TOPIS 및 최신 공개 노선자료 기반 미아사거리역 중앙차로 간선버스 노선 확인: 101, 102, 107, 120, 130, 140, 141, 142, 144, 148, 150, 151, 160, 163, 710
- 한국철도공사: 운영노선 및 KTX/KTX-이음 운행계통
- NOAA Global Monitoring Laboratory: General Solar Position Calculations
- 역 좌표: 공개 지리자료/Wikidata 및 공공 위치자료를 교차 참고

세부 출처·데이터 범위는 [`DATA_SOURCES.md`](./DATA_SOURCES.md)를 참고하세요.

## 로컬 실행
ES module을 사용하므로 파일을 직접 더블클릭하지 말고 간단한 HTTP 서버로 실행합니다.

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속.

## 테스트
```bash
npm test
```

## GitHub Pages 배포
1. 새 public repository를 만듭니다. 예: `my-seat`
2. 이 폴더의 내용을 repository root에 push합니다.
3. GitHub → Settings → Pages → **Deploy from a branch**
4. Branch `main`, folder `/ (root)` 선택 후 Save

## 향후 데이터 확장
`data/routes.js`의 `BUS_ROUTES` 또는 `KTX_ROUTES`에 정류장/역 좌표를 추가하면 계산 엔진 수정 없이 자동으로 확장됩니다.
